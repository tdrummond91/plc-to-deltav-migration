Your analysis workspace

Click a card to open that page. Each page uses the same saved source and project; your review decisions stay separate from the original logic.

Page access: Read only means viewing evidence. Read & write means you can save reviews, groups or the stated settings. These labels describe page content; Project tools remain available on every page. The original L5X is never edited.

Which filter should I use?

Function family on Rungs and Ladder map describes captured instructions: Boolean conditions/results, calculations, PID, timers, and other families. A mixed rung can match several families.

Function on Classification & groups organizes proposed engineering functions such as AI, AO, DI, DO, DC and AC. It can combine several source records. These proposals are not approved DeltaV class assignments.

Reviewed category and review status are your saved decisions. Filtering by a family never changes them. Tags uses object types; Connection map uses direction, routine scope and exact signals.

Arrange your workspace

Use Menu for engineering views, including Programs & routines. Click the PLC Workbench logo to return here. The ? button opens How to review. The footer’s FR / EN buttons switch source wording; Project tools contains translation setup, source selection, backups and Changes & reconciliation. Drag a source divider, or hide its pane. Pop out a saved source to free its original pane; Show source restores it. Separate windows have independent selections. Save, then use Project tools → Refresh saved data in the other window.

To finish: save your edits, then use Stop workspace in the main window or Ctrl+C in its Bash terminal. Chrome’s X closes that window only; the local server and any translation work continue.

FIELD SIGNALS AND DELTAV PACKAGES

Field I/O

Work one field signal at a time. Assign its DeltaV name, then keep its scaling, alarms and references together in a package. Hardware connections are available from each signal’s information button.

BROWSE THE CAPTURED PROGRAM

Programs & routines

Filter the directory, then expand a routine to read its ladder in source order. Hover over a block for an explanation and worked example. Ctrl-click opens an independent help window; keep several open to compare. Open a rung to review its meaning and saved decisions.
