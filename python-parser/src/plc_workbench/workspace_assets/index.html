START HERE

Your analysis workspace

Click a card to open that page. Each page uses the same saved source and project; your review decisions stay separate from the original logic.

Which filter should I use?

Function family on Rungs and Ladder map describes captured instructions: Boolean conditions/results, calculations, PID, timers, and other families. A mixed rung can match several families.

Function on Classification & groups organizes proposed engineering functions such as AI, AO, DI, DO, DC and AC. It can combine several source records. These proposals are not approved DeltaV class assignments.

Reviewed category and review status are your saved decisions. Filtering by a family never changes them. Tags uses object types; Connection map uses direction, routine scope and exact signals.

Arrange your workspace

Use Page for engineering views, including Programs & routines. How to review opens the checkable guide. Project tools contains source selection, Source language, backups and Changes & reconciliation. Drag a source divider, or hide its pane. Pop out a saved source to free its original pane; Show source restores it. Separate windows have independent selections. Save, then use Project tools → Refresh saved data in the other window.

To finish: save your edits, then use Stop workspace in the main window or Ctrl+C in its Bash terminal. Chrome’s X closes that window only; the local server and any translation work continue.
