## Next analysis bundle

Boolean output context groups accepted exact targets while preserving every coil
occurrence and its distinct assign/set/clear action. It retains other writes,
read/write uses, unknown roles and expression reads alongside the coil writers.
Multiple writers are observations, not a selected execution order or final state.

Each accepted target is associated with its declaration kind: ordinary tag or
module input/output/configuration root. This is declaration evidence, not a
verified physical channel or device. Different member/index spellings remain
separate. Rack candidates and dynamic indexes do not become exact addresses.

Predicate and ONS storage reads link to the existing condition graph by source
occurrence. The report follows that graph to find outputs whose captured incoming
context contains those reads; another block on the same rung is not enough.
Repeated reads, self-feedback and separate branch legs remain visible. Expression
reads and unknown-role operands do not become Boolean condition dependencies.
Opaque and stateful contexts keep their qualifications. These links establish
neither effective influence nor shutdown behavior.

Existing alarm, equipment and sensor hints remain scoped to the rung. Their
source may be a comment or any referenced object's name/description; the hint
does not identify a particular output's purpose. Namespace-confounded evidence
stays explicitly unqualified with source navigation. Qualified address and guard
links use the new companion's acceptance results, preserving earlier evidence.

The model stores outputs, shared address uses, condition reads and rung contexts
once. It uses the existing condition graph rather than expanding every writer
and consumer pair or copying condition trees.
